# 비서실 · Office Dashboard

폰이나 PC 브라우저에서 여는 개인용 비서실 대시보드입니다.

- 주소: https://lk199600-ux.github.io/desktop-tutorial/
- 화면에 보이는 내용은 모두 **AES-GCM 암호문**으로 저장되어 있습니다. 이 저장소에는 비밀번호도, 평문 데이터도 들어 있지 않습니다.
- 페이지에서 비밀번호를 입력하면 접속한 기기의 브라우저 안에서만 복호화되어 표시됩니다. (PBKDF2-SHA256 310,000회 → AES-256-GCM)
- 외부 스크립트·폰트·추적 없음. 정적 페이지 하나와 오피스 일러스트 한 장이 전부입니다.

## 화면 기능

- **5개 탭** — 오피스(파트 5곳 현황·오피스 지도) · 회의실(미팅·일정) · 작업실(프로젝트) · 현황(긴급 안건·오늘 챙길 일) · 메모(빠른 메모·대기 안건·참고 링크)
- **자동 D-Day 배지** — 일정마다 오늘 날짜 기준으로 `D-3` · `D-Day` · `D+1`을 계산해 표시 (3일 이내는 빨간색)
- **할 일 체크 저장** — 체크 상태를 이 기기 브라우저(localStorage)에 저장하고, 완료율 `3/6`과 진행률 막대로 표시
- **빠른 메모** — 대시보드 안에서 바로 적는 개인 메모. 입력하는 대로 자동 저장
- **통합 검색** — 상단 검색창에서 모든 탭의 루틴·일정·프로젝트·메모를 한 번에 찾고, 결과를 누르면 해당 위치로 이동
- **다크 모드** — 상단 🌙/☀️ 버튼으로 전환, 선택은 이 기기에 저장

체크·메모·테마 설정은 서버로 전송되지 않고 접속한 기기의 브라우저에만 남습니다. 30분 동안 조작이 없으면 화면이 자동으로 다시 잠깁니다.
